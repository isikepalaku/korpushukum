## Aturan emas
1. Verifikasi dulu, jangan vonis — terdaftar = presumsi sah (pelajaran: Bakti Huria, Pinrang Abadi).
2. Badan hukum ≠ izin usaha simpan pinjam. Closed-loop = Kemenkop; open-loop = OJK.
3. Fokus bongkar sisi **penghimpunan dana** (pidana berat), bukan sekadar bunga/tenor.
4. Pemeriksaan atas dasar tugas Satgas + koordinasi Dinas — bukan tindakan paksa. Indikasi pidana → eskalasi SP Lidik.
5. Setiap ancaman pidana dibaca pasca UU 1/2026.
