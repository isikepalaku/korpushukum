# Pasal 121 — Peraturan Pelaksanaan UU PDP

## Batang Tubuh

- (1) Kewajiban melakukan penilaian dampak Pelindungan Data Pribadi sebagaimana cimaksiad dalam Pasal 120 ayat (1) dilaksanakan sebelum dilakukan pemrosesan Data Pribadi.

- (2) Penilaian dampak Pelindungan Data Pribadi sebagaimana dimaksud pada ayat (1) paling sedikit menruat:

 - a, deskripsi mengenai kegiatan pemrosesan Duta Pribadi dan tujuan pemmscsan Data Pribadi, termasuk kepentingan dari Pengendali Data Pribadi atas pemrosesan Data Pribadh,

 - b -penilaian kebutuhan dan proporsionalitas antara tujuan dan kegiatan pemrosesan Data Pribaci;

 - c. penilaian risiko terhadap hak Subjek Data Pribadi; dan

 - d. Jangkah Pengendali Data Pribadi untuk melindungi Subjek Data Pribadi dari risike pemrosesan Data Pribadi,

- (3) Pengendali Data Pribadi menerapkan langkah Pengendali Data Pribadi untuk melindungi Subjek Data Pribadi dari risiko pemrosesan Data Pribadi sebagaimana dimaksud pada ayat (2) huruf d pada saat pemrosesan Data Pribadi dilakukan.

- (4) Pengendali Data Pribadi mendokumentasikan penilaian dampak Pelindungan Data Pribadi beserta langkah yang digunakan Pengendali Data Pribachi untuk melindungi Subjek Data Pribadi dari risiko pemrosesan Data Pribach,

- (5) Pengendali Data Pribadi harus melakukan peninjauan ulang penilaian dampak Pelindungan Data Pribadi jika terdapat perubahan rsiko pemrosesan Data Pribadli.
