# Pasal 81 — Peraturan Pelaksanaan UU PDP

## Batang Tubuh

- (lt) Pengakhiran pemrosesan Data Pribadi oleh Pengendali Data Pribadi sebagaimana dimaksud dalam Pasal 80 ayat (1) dilakukan dengan cara menghentikan pemrosesan Data Pribadi tersebur.

- (2) Kewajiban pengakhiran pemrosesan Data Pribadi oleh Pengendali Data Pribadi sebagaimana dimaksud pada ayat (1) termasuk dalam hal pemrosesan Data Pribadi melibatkan Pengendali Data Pribaci lainnya dan/ atau Prosesor Data Pribadi.

- (3) Pengendali Data Pribadi harus memberitahukan pengakhiran pemrosesan Data Pribadi sebagaimana dimaksud pada ayat (1) kepada Subjek Data Pribadi.

## Penjelasan Resmi

Cukup jelas.
