# Pasal 80 — Sistem Informasi Administrasi Kependudukan

## Batang Tubuh

(1) 
Pusat Data Cadangan merupakan Pusat Data pengganti 
sementara. 
(2) 
Pusat Data Cadangan sebagaimana dimaksud pada ayat 
(1), berfungsi untuk pemulihan Pusat Data jika terjadi 
keadaan kahar. 
(3) 
Keadaan kahar sebagaimana dimaksud pada ayat (2), 
disebabkan karena kejadian luar biasa dan bencana. 
 
Bagian Keduabelas 
Data Cadangan

## Penjelasan Resmi

Cukup jelas.
