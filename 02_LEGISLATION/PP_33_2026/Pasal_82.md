# Pasal 82 — Peraturan Pelaksanaan UU PDP

## Batang Tubuh

- (1) Pengendali Data Pribadi wajib menghapus Data Pribacti dalam hal:

- a. Data Pribadi tidak lagi diperlukan untuk pencapaian tujuan pemrosesgan Data Pribadi;

- b, Subjck Data Pobadi telah melakukan penarikan kembali persetujuan pemrosesan Data Pribadi;

- ce. térdapat permintaan dari Subjek Data Pribadi, atau

 - d. Data Pribadi diperoleh dan/atau diproses dengan cara melawan hukum.

(2) Kewajiban ...

**=**

- (2) Kewajiban menghapus Data Pribadi dalam hal Data Pribadi diperaleh dan/atau diproses dengan cara melawan hukum sebagaimana dimaksud pada ayat (1) huruf d dilaksanakan dalam hal: a. perolchan dan/atau pemrogesan Data Pribadi yang dilakukan oleh Pengendali Data Pribadi merupakan perbuatan melawan hukum sesuai dengan ketentuan peraturan perundang-undangan;

 6. pelaksanaan sanksi administratif bertupa penghapusan oleh Lembaga: atau

 c terdapat putusan pengadilan yang telah memperoleh kekuatan hukum tetap.

- (3} Kewajiban penghapusan Data Pribadi sebagaimana dimaksud pada ayat (1) dan ayat (2) termasuk dalam hal penghapusan Data Pribadi melibatkan Pengendali Data Pribadi lainnya dan/atau Prosesor Data Pribadi.

- (4) Penghapusan Data Pribadi sebagaimana dimaksud pada ayat (1) dilakukan dengan cara menghapus Data Pribadi sehinggn Data Pribadi tersebut tidak lagi dapat diakses olch selain Pengendali Data Pribadi.

**Pasal B3**

Subjek Data Pribadi tidak dapat mengajukan permintaan penghapusan Data Pribadi jika penarikan persetujuan pemrosesan Data Pribadi yang diikuti dengan penghapusan Data Pribadi telah dilaksanakan oleh Pengendali Data Pribadi sebagaimana dimaksud dalam Pasal 62 ayat (1) huruf b.
