# Rahasia Bank

## Ringkasan
Rezim rahasia bank melindungi kerahasiaan data simpanan nasabah. Untuk kepentingan penyidikan, penyidik Polri dapat meminta **izin pembukaan rahasia bank** kepada **Ketua Dewan Komisioner OJK** — prosedur dan format surat baku telah diterbitkan OJK (2026) untuk aparat penegak hukum.

## Dasar hukum
- **Ps. 40–50A UU Perbankan** (UU 7/1992 jo. 10/1998) — kewajiban rahasia bank & pengecualian; pidana terkait rahasia bank (lihat [[Perbankan]]).
- **UU 4/2026** (perubahan UU P2SK) — pembaruan ketentuan rahasia bank.
- **POJK 44/2024 tentang Rahasia Bank** — rezim teknis pembukaan rahasia bank.

## Prosedur permintaan izin (Format Standar OJK 2026)
Surat permohonan ditujukan ke **Ketua Dewan Komisioner OJK RI** (Gd. Menara Radius Prawiro, Jakarta), struktur baku 5 bagian:

| Bagian | Isi |
|---|---|
| 1. Kop surat | Nomor, Lampiran, Hal |
| 2. Dasar/Rujukan | UU; Laporan Polisi/Laporan Kejadian TP; **Surat Perintah Penyidikan**; **Surat Penetapan Tersangka**; dll. |
| 3. Kronologi | Uraian informasi penyidikan, dugaan TP, nama tersangka, pasal disangkakan |
| 4. Keterangan diminta + alasan + hubungan perkara | Mis. saldo & mutasi rekening periode tertentu — alasan: menelusuri aliran dana hasil dugaan TP (follow the money); hubungan: rekening diduga menampung hasil TP |
| 5. Daftar pihak | Nama, No. identitas, nama bank, No. rekening, keterangan hubungan dengan tersangka |

## Diseminasi OJK ke APH (2026)
- **S-196/KO.16/2026** (7 Agu 2026): Kepala OJK Provinsi Sulselbar → Kapolda Sulsel — penyampaian media diseminasi pembukaan rahasia bank; materi di link `bit.ly/RahasiaBankOJK` (Komik + Video Panduan + Format Standar Surat).
- File tersimpan di `raw/rahasia-bank/`: `Format-Standar.docx` (template surat) + `Komik-Rahasia-Bank-OJK-2026.pdf` (media edukasi).

## Catatan lidik
- Pakai Format Standar ini untuk permintaan pembukaan rekening tersangka (bank gelap, TPPU, fintech ilegal) — format telah disepakati OJK sehingga mempercepat penerbitan izin.
- Dasar rujukan wajib lengkap: LP + Sprindik + Penetapan Tersangka — siapkan sebelum mengirim permohonan.
- Konstruksi pidana terkait: [[Bank Gelap]] (Ps. 46 UU Perbankan), [[TPPU]], [[Kewenangan Penyidikan SJK]].
